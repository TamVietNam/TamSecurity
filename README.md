# Network and Security Projects

This repository contains academic projects completed during my Information Security studies at HCMUTE.

Designed a simulated enterprise network using routing, switching, VLAN segmentation, access control, and basic redundancy.

### 2. Network Monitoring
Monitored network devices, analyzed traffic and logs, and identified connectivity and security issues in a controlled lab environment.

### 3. Network Configuration and System Administration
Configured network devices and basic network services, administered Linux and Windows Server systems, and performed troubleshooting.
